    Come revisionare

    1. Correggi i testi nell’editor accanto all’anteprima.
    2. Seleziona una parola o una frase per applicare uno stile o aggiungere un commento.
    3. Sposta o elimina le slide interne con i comandi della slide.
    4. Invia bozza per applicare le modifiche, oppure seleziona Approva per passare alla prova visiva.
